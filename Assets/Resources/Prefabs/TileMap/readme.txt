

해당 폴더내에 있는 타일맵은 아래의 규칙을 따릅니다.

타일맵은 Start,End를 제외하고는 2방향이 뚫려있습니다. 

타임맵은 Start,End일 경우 한개의 방향이 뚫려있습니다.


Startbase (시작)

스테이지가 시작될때 시작하는 타일맵입니다.

해당 영어가 붙어있는 방향으로 길이 뚫려 있습니다.

EndBase (보스)

스테이지가 완료되는 타일맵 지반입니다

해당 영어가 붙어있는 방향으로 들어옵니다.





East, West , North, South  (동서남북 폴더)

나아가는 방향입니다.

East : 서쪽에서 동쪽으로 다음을 진행할때 사용합니다.
해당 폴더의 타일맵은 반드시 서쪽이 뚫려있으며 나머지 방향은 랜덤하게 뚫으면 됩니다.

West : 동쪽에서 서쪽으로 다음을 진행할때 사용합니다.
해당 폴더의 타일맵은 반드시 동쪽이 뚫려있으며 나머지 방향은 랜덤하게 뚫으면 됩니다.

North : 남쪽에서 북쪽으로 다음을 진행할때 사용합니다
해당 폴더의 타일맵은 반드시 남쪽이 뚫려있으며 나머지 방향은 랜덤하게 뚫으면 됩니다.

South : 북쪽에서 남쪽으로 다음을 진행할때 사용합니다.

해당 폴더의 타일맵은 반드시 남쪽이 뚫려있으며 나머지 방향은 랜덤하게 뚫으면 됩니다.
